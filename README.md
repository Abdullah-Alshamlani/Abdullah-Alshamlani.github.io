# Abdullah Al-Shamlani — Personal Website

Bilingual (Arabic / English) personal portfolio for **Abdullah Al-Shamlani**, Backend / .NET Software Developer.

🌐 **Live:** https://abdullah-alshamlani.github.io

## Features
- Dark, tech-inspired design with an animated terminal hero
- Arabic ⇄ English language switch with full RTL/LTR support (remembers the visitor's choice)
- Sections: About, Tech stack, Experience timeline, Projects, Education & certifications, Contact
- Fully responsive, single static `index.html` — no build step

## Tech
HTML5 · CSS3 · Vanilla JavaScript · Hosted on GitHub Pages
